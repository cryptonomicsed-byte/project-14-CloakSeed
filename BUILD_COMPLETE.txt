🎓 HOW IT WORKS (In 60 Seconds)

1. User chooses a theme (animals, colors, food, etc.)
   → App has 2,048 custom words for that theme

2. App generates a real BIP-39 seed (12 words)
   → "abandon able zone kind dragon ..."

3. App encodes seed using the cipher
   → Each word mapped to theme word
   → Result: "fluff spark moon kind dragon ..."

4. User writes ONLY the cloak phrase in notebook
   → No one knows what "fluff spark moon" means

5. User imports the REAL seed into MetaMask
   → MetaMask has no idea it came from a cloak

6. User can later recover by:
   - Paste cloak phrase
   - Select cipher
   - App shows real seed
   - Import into any wallet

🔑 Only user knows both:
   - Cloak phrase (written in notebook)
   - Cipher mapping (in their browser)
