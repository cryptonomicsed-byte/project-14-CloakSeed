KEY INTERACTION PATTERNS:

1️⃣  SETUP WORKFLOW (First Time)
   Landing → Dashboard (empty) → Generator → Show Real Seed + Cloak → 
   Write Cloak → Import Real Seed to MetaMask → Save Cloak → Dashboard

2️⃣  RECOVERY WORKFLOW (Restore Wallet)
   Dashboard → Decoder → Select Cipher → Paste Cloak Phrase → 
   Decode → Show Real Seed → Copy to MetaMask → Done

3️⃣  SECURITY WORKFLOW (Backup)
   Dashboard → Settings → Download Backup → Encrypt JSON locally → 
   Store in cloud or cold storage → Keep safe

4️⃣  PANIC WORKFLOW (Coercion Defense)
   Decoder → Generate Panic Phrase → Memorize or Destroy → 
   If threatened, give panic cloak (shows empty wallets) → Safety

5️⃣  EXPORT WORKFLOW (New Device)
   Old Device: Settings → Download Backup → Encrypt
   New Device: Import backup → Decrypt → Restore ciphers → Done
